# Local product photos

Place JPEG, JPG, JFIF, PNG or WebP files here, named after the product URL slug.
Example: a product at /produits/samsung-a55 uses samsung-a55.jpg.
Images are served through /local-images/samsung-a55. Missing images use the shop logo.
Only lowercase slug filenames are supported. The route is for local testing; deploy a media
storage service before production. The admin file picker still previews files only.
